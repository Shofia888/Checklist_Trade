TAHAP A — TEMPEL & SIMPAN KODE:

  1. Klik tombol "Salin Kode Apps Script" di kanan atas kotak ini.

  3. Lihat deretan ikon di bagian atas (di sebelah kiri tulisan "▷ Jalankan"), klik ikon Disket (💾 Simpan project ke Drive). Tunggu sampai tulisan "Perubahan belum disimpan" di atas hilang.

TAHAP B — TERAPKAN (DEPLOY) MENJADI WEB APP:

  1. Klik tombol biru "Terapkan" di pojok kanan atas layar → pilih "Deployment baru".
  2. Akan muncul jendela kecil. Di sebelah kiri tulisan "Pilih jenis", klik ikon Roda Gigi (⚙️) → lalu klik "Aplikasi web".
  3. Biarkan kotak Deskripsi kosong, dan biarkan Jalankan sebagai tetap "Saya (email Anda)".
  4. Pada bagian "Siapa yang memiliki akses", klik pilihannya lalu ubah dari "Hanya saya" menjadi "Siapa saja" (Anyone). (Wajib diubah ke "Siapa saja" agar HTML bisa mengirim data!)
  5. Klik tombol biru "Terapkan" di kanan bawah jendela tersebut.

TAHAP C — BERIKAN IZIN AKSES (OTORISASI GOOGLE):

  1. Jika muncul tombol biru "Izinkan akses" (Authorize access), klik tombol tersebut.
  2. Pilih Akun Google Anda (pemilik file Google Sheets Trading Jurnal).
  3. Jika muncul layar peringatan "Google belum memverifikasi aplikasi ini", jangan khawatir (itu karena ini script buatan Anda sendiri):
    • Klik tulisan kecil "Lanjutan" (Advanced) di kiri bawah.
    • Klik tulisan "Buka Untitled project (tidak aman)" di paling bawah.
    • Scroll ke bawah lalu klik tombol "Izinkan" (Allow).

TAHAP D — SALIN URL & TEMPEL KE HTML INI:

  1. Setelah selesai, akan muncul jendela Deployment baru berisi URL Aplikasi Web (awalan https://script.google.com/macros/s/.../exec).
  2. Klik tombol "Salin" (Copy) di bawah URL tersebut.
  3. Kembali ke halaman HTML ini, tempelkan URL tersebut ke kotak Langkah 1 di atas, lalu klik "Simpan Koneksi". Selesai!
